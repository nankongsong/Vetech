## 二、技术选型

| 维度 | 选型 | 理由 |
| --- | --- | --- |
| 框架 | 原生 HTML + CSS + JavaScript（ES6+） | 轻量、零依赖、与 `web` 静态资源目录契合，便于直接预览 |
| 样式 | 原生 CSS3（CSS 变量 + 弹性盒 + 网格） | 减少构建链，便于维护 |
| 图标 | 内联 SVG / Unicode 符号 | 避免外链依赖 |

| 字体 | 系统字体栈 + 中文回退（PingFang SC / Microsoft YaHei） | 跨平台一致体验 |
| 预览 | 浏览器直接打开 `index.html` | 简单可演示 |

## 五、模块设计

### 5.1 表头
- 固定定位（`position: sticky; top: 0`）。
- 标题居中、日期靠右。

### 5.2 分区折叠面板
- 通用组件 `CollapsePanel`：
  - 标题 + 右侧操作区 + 箭头图标。
  - 折叠状态写入 `state.ui.collapsed[key]`。

### 5.3 表格
- 通用 `DataTable`：
  - 支持列定义、单元格自定义渲染、序号列、操作列图标。
  - 空数据提示。

### 5.4 下拉选择
- 通用 `Select`：
  - 业务类型支持树形展开。
  - 点击外部关闭、键盘上下选择、回车确认。

### 5.5 弹窗
- 通用 `Modal`：
  - 居中遮罩、ESC 关闭、点击遮罩关闭。
  - 标题、内容、底部操作区。
- `ConfirmModal`：用于删除、关闭、提交等确认。

### 5.6 补录行程弹窗
- 字段：出行人、出发/到达城市、出发/到达日期、行程说明。
- 校验：
  - 必填。
  - 到达日期 ≥ 出发日期，且不超过今天。
  - 人员+日期范围与已存在行程不可重叠。

### 5.7 补助日历弹窗
- 顶部信息卡：出差类型、开始/结束日期、行程、补助金额、标准总额。
- 网格：每行一天，列为日期 + 餐费/交通/通讯补助列。
- 复选联动：
  - 日期行复选 → 选中当天所有项。
  - 补助项列复选 → 选中该列所有日期。
  - 表头全选 → 全选/全取消。
  - 行/列全选时，对应表头复选框高亮。
- 金额：
  - 标准金额 = 餐费(按城市类型) + 交通(40) + 通讯(40)。
  - 勾选项合计 = 补助金额；标准合计 = 申请金额。

## 六、计算规则

### 6.1 补助信息生成
- 当补录行程保存后，自动按行程生成一条补助信息。
- 补助城市 = 行程到达城市。
- 补助天数 = 到达日期 - 出发日期 + 1。
- 申请金额 / 补助金额 = 0（需打开补助日历勾选后才有值）。

### 6.2 费用合计
- 补助总金额 = ∑ subsidyAmount
- 餐费补助 = ∑ 餐费项
- 交通补助 = ∑ 交通项
- 通讯补助 = ∑ 通讯项

### 6.3 分摊
- 第 1 行 = 100% − ∑(第 2+ 行比例)，比例保留两位小数。
- ∑(第 2+ 行) > 100% → 清空超限输入框。
- 均摊：每行比例 = 1/n，若除不尽差值放首行。
- 分摊金额 = 补助总金额 × 分摊比例。
- 合计行：分摊比例 = 100%，分摊金额 = ∑ 分摊金额。

## 八、交互与可访问性

- 所有可点击元素鼠标移入显示 `cursor: pointer`。
- 输入框聚焦蓝色描边。
- 必填字段使用红色 `*` 标识。
- 弹窗遮罩点击关闭，ESC 关闭。
- 表格操作列使用图标 + 悬浮 Tooltip。

## 九、代码质量

- 模块化 ES5/ES6 风格，无打包工具。
- 函数单一职责，命名语义化。
- 关键计算逻辑写注释。
- 兼容主流现代浏览器（Chrome 100+ / Edge 100+）。

## 十、运行方式

1. 进入 `web/` 目录。
2. 直接双击 `index.html` 或通过本地静态服务器（如 `python -m http.server`）访问。
3. 浏览器打开后即可看到完整报销单页面，可进行交互。
